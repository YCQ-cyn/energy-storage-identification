# 用户侧储能识别

**简体中文** | [English](README.en.md)

面向电力营销运维的用户侧储能辅助排查项目。利用用户日负荷曲线和当前分时电价政策，分析储能充放电留下的负荷响应，形成用户级排查结果，帮助业务人员确定优先复核对象。

## 业务背景与目标

用户侧储能主要通过低电价时段充电、高电价时段放电降低用电成本。设备运行会叠加到用户原有负荷上，但生产启停、负荷转移和光伏发电也会改变曲线，仅靠某一时刻的负荷升降难以判断储能行为。

项目以“利益驱动的充放电行为”为识别对象，将负荷变化、充放电持续性以及相对电价偏好结合起来。业务上重点回答：哪些用户表现出较强的储能行为证据，哪些用户需要进一步核查，以及结论基于多少个有效日。

实际排查时通常只有用户总负荷，无法取得储能设备的独立功率。为此，训练阶段利用用户有功功率和储能充放电功率建立监督，部署阶段仅需要用户有功功率和适用的峰、平、谷时段。

## 业务使用流程

1. 上传用户日负荷表格：每行是一户一天的数据，包含日期、户号及间隔 15 分钟的 96 个有功功率点。
2. 选择数据对应的电价政策：根据记录月份生成适用的峰、平、谷时段，无需提供具体电价金额。
3. 自动识别有效记录：日期、户号或任一负荷点无效的记录跳过推理，并保留总天数与有效天数。
4. 生成用户级排查结果：在页面预览、搜索户号并下载结果表，供人工复核和后续现场排查使用。

本地服务提供文件上传、表格区域内滚动、户号片段搜索、匹配文字高亮和结果下载。文件在本机处理。

## 识别方法

### 1. 学习储能运行与总负荷之间的联动

第一阶段通过自监督学习，从同步采集的用户有功功率和储能充放电功率中学习时序表征。两条曲线同步增强，保留运行时段及联动关系；方差、不变性和协方差正则化用于维持表征的信息量。

网络结合因果时间卷积网络与长短期记忆网络，提取局部功率变化及日内持续运行结构，为后续教师和学生模型提供基础表征。

### 2. 让教师同时判断物理响应与套利行为

第二阶段教师使用训练时可获得的储能设备功率。行为监督基于原始功率数值构造，再与归一化网络输入配合，避免将逐曲线缩放后的幅值直接当作原始物理量。

| 证据层次 | 教师学习的内容 | 业务含义 |
| --- | --- | --- |
| 物理联动 | 用户有功功率与储能充放电功率的对齐、成对边界和连续运行结构 | 判断设备动作是否在总负荷中留下可解释的响应 |
| 响应可见度 | 充电可见度、放电可见度及响应可信度 | 区分清晰的储能响应与被其他负荷变化掩盖的弱证据 |
| 电价行为 | 低电价充电偏好、高电价放电偏好及充放电价位关系 | 判断运行是否符合通过分时电价节约成本的行为倾向 |

教师将这些证据组合为连续的储能行为分数。峰谷关系提供行为依据，平价时段的动作仍可通过物理联动和响应证据参与判断；不会将所有平价运行直接视为无储能。

### 3. 用政策迁移减少对固定时钟的依赖

电价政策变化后，峰谷时段会移动，但低价充电、高价放电的经济动机仍然存在。训练将储能运行片段按相对电价角色重定位，并同步重构用户有功功率，使充放电动作与新的政策上下文匹配。

教师物理与响应分支屏蔽政策上下文，行为分支保留相对电价角色并屏蔽季节通道。推理按当前政策生成时段特征，目标是降低模型对旧政策固定时刻的依赖。

当前实现内置旧政策和新政策。新增政策需先配置时段，并验证迁移效果。

### 4. 用反事实样本检查证据是否可靠

训练通过时序或符号错配、用户有功功率响应衰减以及去除储能分量等方式，构造与原样本成对的反事实。模型需要学习：当物理联动被破坏，或储能响应减弱时，相应的行为证据应下降。

这些样本用于连续目标学习和成对排序。在缺少严格非储能用户真值的情况下，它们提供训练参照，但不能作为真实非储能标签。

### 5. 将教师知识传给仅需总负荷的学生

学生输入为归一化用户有功功率、正向变化量、负向变化量、相对电价角色和角色跳变。通过多目标蒸馏与成对约束，学习教师给出的储能行为、物理证据、响应可信度、活跃强度和充放电可见度。

部署时无需储能设备功率，也不需要将每天数据拼成连续多日序列。识别首先在单日层面进行，再汇总为用户级结果。

训练、验证和测试按用户切分，同一户号的全部日期只属于一个集合。验证关注表征是否塌缩、教师各目标的拟合情况、反事实排序及政策迁移稳定性；学生还需检查对教师目标的保留程度。反事实上的区分能力用于方法验证，真实业务识别效果仍需现场真值评估。

## 排查结果与业务解释

页面预览及简表下载包含四列：**户号、储能情况、总天数、有效天数**。详细输出还提供每日结果及各等级有效日占比。

| 分数范围 | 排查等级 |
| --- | --- |
| 大于 80 | 强储能 |
| 大于等于 60 且小于等于 80 | 中储能 |
| 小于 60 | 无或储能占比不高 |

用户级分数采用有效日中最高 20% 日分数的均值，选取天数向上取整且至少为一天。这一规则强调用户在活跃日的储能行为证据；有效天数较少时，应结合更多数据复核。

分数表示行为证据强度，尚未经过真实非储能用户的概率校准。强、中等级适合用于排查优先级；较低分数也可能意味着储能较弱、未运行或被其他负荷掩盖，不能直接等同于未安装设备。光伏、生产启停、自备电源和计量异常需结合人工复核。

## 环境配置

Python 3.10 或更新版本，PyTorch 2.1 或更新版本。网页服务需要 Java 开发工具包 17 或更新版本。训练可选使用 NVIDIA 图形处理器及相应的计算运行环境。

在仓库根目录执行以下命令。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 快速推理

仓库包含三个训练完成的模型权重，不包含原始业务数据、处理后的数据、用户清单或训练缓存。

Windows 用户可双击根目录的 `start_web.bat`，在本机浏览器中上传表格并下载结果。

```text
http://127.0.0.1:8765
```

也可直接执行推理命令。

```powershell
python -m storage.infer `
  --ckpt train_student/best_model_student.pt `
  --input_path D:/private-data/input.xlsx `
  --output_path D:/private-data/storage_result.xlsx `
  --policy_name new
```

推理输入推荐首行为 `数据日期`、`户号`，随后为 `0:00` 至 `23:45` 的 96 个有功功率点，间隔 15 分钟。
