# 数据格式

## 推理输入

推理文件支持 `.xlsx` 和 `.csv`。推荐首行为：

```text
数据日期  户号  0:00  0:15  0:30  ...  23:30  23:45
```

要求如下：

- 每行表示一个用户的一天数据。
- 负荷曲线为 96 个 15 分钟有功功率点。
- 日期支持 Excel 日期、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD` 和常见中文日期格式。
- 日期列兼容“数据日期”“日期”“用电日期”“采集日期”等常见名称。
- 户号列兼容“户号”“关联用户号”“用户号”“用户编号”等常见名称。
- 任一负荷点缺失的记录不会进入模型，有效天数仅统计完整记录。

## 训练输入

正式训练数据应包含：

- 用户标识列，默认名称为 `关联用户号`。
- 日期及月份信息。
- 单日 96 点有功功率 `P`。
- 与 `P` 同步的单日 96 点储能功率 `Q`。

具体字段解析由 `TCN/adding_problem/utils.py` 完成。由于训练数据来源可能不同，首次使用前应根据实际表头核对 `load_storage_data` 的字段映射，不应仅修改文件名后直接训练。

## 数据隔离

建议将私有数据保存在仓库之外，例如：

```text
D:/storage-private-data/
├─ processed_result.xlsx
└─ data_split/
   └─ user_split.csv
```

仓库的 `.gitignore` 已排除常见数据格式，但提交前仍应检查 `git status`。
