# 模型说明

## 模型目标

模型用于从用户级日负荷曲线中输出储能行为证据，而非声明用户是否安装了某一具体设备。核心目标是识别利益驱动下相对稳定的谷充峰放行为及其在有功功率中的可见响应。

## 模型链路

1. Stage-1：使用 `P/Q` 学习稳定的时序表征。
2. Stage-2：利用完整信息训练多头教师，目标覆盖物理证据、响应可信度和套利行为。
3. 蒸馏数据：将教师连续目标、政策迁移样本和反事实样本整理为学生监督。
4. 学生：仅用 `P` 派生特征和相对电价角色学习教师证据。
5. 推理：先产生每日连续分数，再按用户有效天数进行汇总分级。

## 政策泛化

模型不直接学习固定的充放电时钟，也不使用具体电价金额。峰、平、谷被编码为相对角色，因此政策时段变化时可重新生成角色序列。该设计降低旧政策时段与模型输出之间的捷径相关，但不保证对所有未见政策自动有效，显著政策变化仍应进行目标域诊断。

## 已知限制

- 缺少严格非储能用户真值时，不能直接报告真实二分类准确率。
- 纯 `P` 曲线可能混合光伏、生产启停、负荷转移和计量异常。
- 极少有效天数用户的用户级结论稳定性较弱。
- 阈值是业务筛查规则，应结合新区域、新政策和现场核查结果校准。

## 推荐使用方式

- 将模型用于候选用户排序和辅助排查。
- 保留每日分数、有效天数和用户级分布，避免只保存最终标签。
- 新政策上线后抽取代表性用户进行人工复核和漂移诊断。
- 不将伪负、GAN 候选或政策反事实直接视为真实非储能标签。
