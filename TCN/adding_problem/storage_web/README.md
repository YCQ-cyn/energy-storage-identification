# 用户侧储能智能辅助排查服务

双击项目根目录下的 `启动用户侧储能排查服务.bat`，程序会自动检查 JDK、Python 推理依赖、模型文件和端口，按需编译 Java 服务，并打开浏览器。

启动器默认使用 `8765` 端口。如果服务已经运行，会直接打开现有页面；如果端口被其他程序占用，会在窗口中显示占用进程。需要更换端口时，可设置环境变量 `STORAGE_WEB_PORT`。需要指定 Python 环境时，可设置 `STORAGE_PYTHON` 指向对应的 `python.exe`。

启动失败时窗口不会直接关闭，详细错误保存在 `storage_web/startup-error.log`。

仅检查环境、文件、端口和 Java 编译而不启动服务，可在项目目录执行：

```bat
启动用户侧储能排查服务.bat -Check
```

## 输入格式

建议使用 `.xlsx`，首行依次为：`数据日期`、`户号`、`0:00`、`0:15` … `23:45`。同时支持 `.csv`；旧版 `.xls` 请先另存为 `.xlsx`。

系统同时兼容：

- 日期列：`数据日期`、`日期`、`用电日期`、`采集日期` 等常见名称。
- 户号列：`户号`、`关联用户号`、`用户号`、`用户编号` 等常见名称。
- 负荷列：96个15分钟时刻列，或 `P1-P96`。
- 日期值：Excel日期、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`、中文年月日等常见格式。

日期、户号或任一负荷点缺失的记录不会进入模型，有效天数仅统计完整记录。

## 输出格式

页面预览和下载Excel均只包含：`户号`、`储能情况`、`总天数`、`有效天数`。

网页服务默认监听 `http://127.0.0.1:8765`，上传文件和结果只保存在本机，临时任务保留24小时。
